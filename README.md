# Steal My Focus

**Steal My Focus** is a GNOME Shell extension that immediately brings any window demanding attention into focus.
When an application requests attention, the window is activated at once instead of flashing or waiting for user action.

---

## Installation

You can install the extension from **extensions.gnome.org** once it is published.

To install manually during development:

1. Create a folder in your extensions directory:
   `~/.local/share/gnome-shell/extensions/steal-my-focus@yourname.github.io`
2. Add the extension files:

   * `extension.js`
   * `metadata.json`
3. Reload GNOME Shell:
   Press **Alt + F2**, type `r`, and press **Enter**.
4. Enable the extension using GNOME Extensions or GNOME Tweaks.
